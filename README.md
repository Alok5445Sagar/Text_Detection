# 📖 Overview

The **Text Detection System** is a Computer Vision and Optical Character Recognition (OCR) project developed to identify, localize, and extract text from images or live video streams in real time.

The system processes visual input using image preprocessing and OCR techniques to accurately detect textual content from:
- 📄 Documents
- 🛣️ Signboards
- 📰 Printed text
- 📦 Product labels
- 📱 Digital displays

This project demonstrates:
- Computer Vision
- OCR-based text extraction
- Real-time image processing
- Pattern recognition
- Intelligent text analysis

```text

          ↓

          ↓
OCR Processing
          ↓
Character Recognition
          ↓
Extracted Text Output
```

---

# 📸 How It Works

1. The system captures an image or video frame.
2. Image preprocessing techniques improve text visibility.
3. Text regions are detected using Computer Vision methods.
4. OCR extracts characters and words from the detected regions.
5. The extracted text is displayed or stored for further processing.

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/Alok5445Sagar/Text-Detection.git
```

## Navigate to Project Directory

```bash
cd Text-Detection
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Install Tesseract OCR

### Windows
- Download and install Tesseract OCR
- Add Tesseract to system PATH

### Ubuntu/Linux

```bash
sudo apt install tesseract-ocr
```

---

# ▶️ Run the Project

```bash
python text_detection.py
```
